# Brainstorming Flow Finance Parser

## Goal Utama

Mengurangi friction saat capture transaksi tanpa mengubah workflow utama yang sudah nyaman.

Source of truth tetap Google Sheet.

AI/App hanya menjadi:

> "lapisan input pintar"

---

# Flow Saat Ini

WhatsApp Chat ↓ Manual input ke Google Sheet ↓ Aplikasi sync ke 2 aplikasi keuangan

---

# Masalah Utama

Bukan di pencatatan.

Masalah utama sebenarnya:

- input ulang ke Google Sheet
- memilih category
- memilih account
- menjaga konsistensi data
- mencegah duplicate

Terutama karena account sangat banyak (23 account).

Jadi full otomatis untuk account selection kemungkinan tidak realistis.

Yang lebih penting:

> mempercepat approval.

---

# Final Recommended Flow

WhatsApp ↓ Copy paste chat ↓ Local web app / self-hosted app ↓ Parser ↓ Suggestion engine ↓ Human review cepat ↓ Append ke Google Sheet ↓ Auto sync ke aplikasi lain

---

# Kenapa Flow Ini Paling Cocok

Karena:

- tetap fleksibel
- tetap cepat capture transaksi
- minim maintenance
- tidak bergantung WhatsApp API
- AI cost kecil
- tetap compatible dengan workflow sekarang
- Google Sheet tetap bisa pakai formula
- scalable untuk banyak account

---

## Google Sheet = Source of Truth

# Core System Design

## 1. Parser

Parsing format seperti:

```text
Semangka => 2k
Semangka = 2k
Semangka 2k
```

Nominal parsing:

```text
2k
2rb
2000
2.000
Rp2.000
```

→ menjadi integer.

---

# 2. Suggestion Engine

Bukan full AI.

Lebih efektif menggunakan:

- histori transaksi
- statistik
- rule engine
- fuzzy matching
- optional AI fallback

---

# 3. Initial Mapping dari Histori 2023–Sekarang

Histori lama adalah aset paling penting.

Data histori bisa dipakai untuk membangun:

- keyword → category
- keyword → account
- merchant recognition
- alias recognition
- confidence scoring

Contoh:

| Keyword  | Category   | Count |
| -------- | ---------- | ----- |
| semangka | Groceries  | 28    |
| nasi tim | Restaurant | 14    |
| stopper  | Fishing    | 11    |

---

# 4. Account Selection

Karena account cukup banyak (23 account), account selection lebih baik tetap manual.

Fokus sistem:

- mempercepat input
- mengurangi typo
- mempercepat approval

Bukan mencoba full otomatis.

User kemungkinan tidak keberatan memilih account secara manual selama:

- UI cepat
- dropdown nyaman
- searchable
- bisa keyboard shortcut
- recent account mudah dipilih

Dengan pendekatan ini:

- sistem lebih sederhana
- maintenance lebih ringan
- behavior lebih predictable
- effort development jauh lebih kecil
- risiko salah account lebih rendah

---

# 5. Smart Learning

Setiap approval user menjadi training data baru.

Contoh:

```text
Cilot => Snack
```

Maka next time sistem otomatis mengikuti.

Jadi sistem makin personal dari waktu ke waktu.

---

# 6. Duplicate Detection

Sistem mencegah double input dengan:

- hash transaksi
- pengecekan histori
- nominal sama
- waktu berdekatan

---

# AI Positioning

AI bukan komponen utama.

AI hanya dipakai untuk:

- transaksi ambigu
- natural language rumit
- OCR struk
- fallback saat confidence rendah

Contoh:

```text
Titip Bu RT
Keperluan acara
Bayar keamanan
```

Karena:

- AI mahal
- AI tidak konsisten
- domain transaksi sangat personal
- histori user jauh lebih berharga

---

# Recommended Processing Pipeline

## Step 1 — Parse transaksi

```text
Semangka => 2k
```

↓

```json
{
  "item": "Semangka",
  "amount": 2000
}
```

---

## Step 2 — Cari histori

Cari:

- category paling sering
- account paling sering
- alias mirip

---

## Step 3 — Fuzzy Matching

Contoh:

```text
smangka
```

→ cocok ke:

```text
semangka
```

---

## Step 4 — Optional AI Fallback

Jika confidence rendah.

---

## Step 5 — Human Approval

User approve/edit cepat.

---

## Step 6 — Append ke Google Sheet

Menggunakan:

```text
spreadsheets.values.append
```

Dengan:

```text
INSERT_ROWS
```

Jadi data lama tidak tertimpa.
