# Smart Financial Inbox — Task Breakdown for AI Agent

## Development Principles

## Git Workflow Rules (MANDATORY)

AI agent MUST follow these rules:

- NEVER commit directly to `main`
- NEVER edit code directly on `main`
- EVERY task MUST use its own branch
- EVERY completed task MUST be squash merged into `main`
- Branch MUST be renamed after merge using prefix `merged/`

---

## Branch Naming Convention

Format:

```text
feature/task-XXX-short-description
```

Examples:

```text
feature/task-001-initialize-nextjs
feature/task-014-build-chat-parser
feature/task-023-add-category-dropdown
```

---

## Merge Strategy

After task completion:

```bash
# switch to main
git checkout main

# squash merge
git merge --squash feature/task-XXX-short-description

# commit
git commit -m "feat: short description"

# rename merged branch
git branch -m feature/task-XXX-short-description merged/feature/task-XXX-short-description
```

---

## Commit Rules

- Small commits preferred
- One logical change per commit
- Use conventional commits

Examples:

```text
feat: add whatsapp chat parser
fix: normalize amount parser
refactor: simplify table state management
```
